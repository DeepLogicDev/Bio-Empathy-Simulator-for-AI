# Bio Empathy Simulator AI

This project simulates empathy by detecting human emotions using a trained deep learning model. It uses a Flask backend with a React frontend.

## Features
- Real-time emotion recognition
- Frontend interface for interaction
- REST API for model inference

## Installation

```bash
cd backend
pip install -r requirements.txt

cd ../frontend
npm install
```

## Running the App

```bash
# Backend
cd backend
python app.py

# Frontend
cd ../frontend
npm start
```
